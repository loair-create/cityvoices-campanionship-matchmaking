# Companionship matchmaking (Google Sheets + Apps Script)

Staff use a **Google Sheet** for sign-ups and matching. **Google Apps Script** powers optional dashboards, a JSON API, public profile links, PDFs, volunteer sync, and spreadsheet menus.

**Start here:** open **[`IMPLEMENTATION.md`](IMPLEMENTATION.md)** for step-by-step setup (sheet → paste code → deploy → optional Lovable/proxy).
